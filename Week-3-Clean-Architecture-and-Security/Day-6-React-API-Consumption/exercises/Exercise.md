# Exercise — Update the User List

Open `src/App.jsx` and make these changes:

1. Remove each user's city from the card. Keep the name and email.
2. Show the total number of users above the cards.
3. Show a message when the user list is empty.

## Hints

- Use `users.length` to get the number of users.
- Check whether `users.length === 0` before showing the cards.
- Keep `users.map()` for displaying the cards when users are available.

## Check Your Work

- [ ] Cards show each user's name and email, but not the city.
- [ ] The page shows the total number of users.
- [ ] An empty list displays a helpful message.
